## This repository is PUBLIC

Everything committed here is world-readable, forever, including git history.

**Never write any sensitive information into any file in this repo.** That includes:

- No passwords, API keys, tokens, secrets, or credentials of any kind.
- No private infrastructure details that would help an attacker (internal hostnames,
  IPs, account IDs, server paths, deployment credentials).
- No personal information about anyone.

The only personal details allowed are:

- The name **Roman Neviantsev** (as the app's developer/operator).
- The address **support@pawlapalabra.com**.

Nothing else. In particular, personal email addresses (e.g. private Gmail accounts),
phone numbers, home or postal addresses, and third-party people's details must never
appear here.

## Rule for Claude

**Before adding any personal information to any file in this repo, stop and explicitly
ask the user whether it is OK to write it here.** This applies to every file — code,
HTML, docs, config, commit messages — and to information beyond the two allowed items
above. Do not assume prior approval carries over; ask each time.

If you notice sensitive information already present in a file, flag it to the user
instead of silently leaving it in place.
